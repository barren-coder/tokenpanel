# TokenPanel 使用说明

一个小巧的 Windows 桌面悬浮窗，实时显示你各个 AI 套餐的**使用量**和账户**余额**。
不用安装、不用管理员权限、不联网上传任何数据（只向你自己的服务商查额度）。

**版本 v1.3.0** ｜ 运行环境：Windows 10 / 11（x64），无需装 .NET 或 Python

---

## 一、怎么启动

1. 解压 ZIP 到任意位置（建议 `D:\Tools\TokenPanel` 这类不常用的目录，
   别放桌面，容易被随手删）
2. **双击 `TokenPanel.vbs`** —— 这是最省事的方式，全程不会出现黑色窗口
3. 屏幕右下角出现小悬浮窗，托盘区（时间旁边）多一个图标

### 想要一个好看的快捷方式？

双击 **`创建快捷方式.cmd`**，会在同目录生成 `TokenPanel.lnk`，
以后双击它就行。想放到桌面或开始菜单，把这个 `.lnk` 复制过去即可。

> `.lnk` 里存的是绝对路径，**移动文件夹后要重新运行一次 `创建快捷方式.cmd`**。
> `.vbs` 是按自身位置找程序的，随便移动都能用。

> **启动失败排查**：改用 `debug-token-pocket.cmd` 启动（会留一个黑窗口），
> 里面会显示具体报错。

## 二、怎么用

| 操作 | 效果 |
|---|---|
| **单击**悬浮窗 | 展开 / 收起（展开能看到每个账户的 5 小时、7 天明细） |
| **双击**悬浮窗 | 刷新：圆环转一圈 + 数字跳动，1 秒后显示最新额度 |
| **拖动**悬浮窗 | 移到任意位置。靠近屏幕**左右边缘**且离任务栏 150 像素以上会自动竖排 |
| **右键**悬浮窗 | 菜单：显示面板 / 立即刷新 / 设置 / 开机自启 / 关于 / 退出 |
| 右键托盘图标 | 同一套菜单 |

**悬浮窗始终在最上层**，点别的窗口不会把它盖住。

**位置会自动记住**，下次启动回到上次的位置。拖到底部任务栏附近会保持横排，
拖到左右两侧中间位置才转竖排——这样不会挡住任务栏。

## 三、怎么配账户

右键 → **设置**。

1. 左边列表选一个账户，或点 **`+ 添加账户`**
2. 选模板（顶部一排）：

| 模板 | 适合谁 | 要填什么 |
|---|---|---|
| **Token Plan** | MiniMax / Kimi / 智谱 GLM 的 Coding Plan | 只填 **API Key**（地址已内置） |
| **官方** | Claude Code / Codex 订阅，以及 **WorkBuddy 积分** | Claude/Codex 不用填 Key，自动读本机凭据；WorkBuddy 点「授权登录」登录一次 |
| **账户余额** | DeepSeek / 硅基流动 / OpenRouter / 阶跃星辰 的钱包余额 | 选供应商 + 填 **API Key** |
| **通用模板** | 其他 OpenAI 兼容网关 | 填 BaseURL + Key |
| **NewAPI** | 自建或第三方 NewAPI 面板 | BaseURL + Access Token + User ID |
| **自定义** | 任何返回 JSON 的接口 | URL + Key + 提取路径 + 倍数 + 单位 |

3. 填完点 **`测试脚本`**，绿字表示成功、能看到数字
4. 点右下角 **`保存配置`**

> **WorkBuddy 积分怎么接**
>
> 模板选 **官方** → 供应商选 **WorkBuddy** → 点「短名」右边的 **`授权登录`**，
> 在弹出的浏览器里登录 `www.workbuddy.cn`（登录成功会自动关窗）。
> 之后每 30 分钟后台查一次（无头 Chrome，约 5 秒，不弹窗）。
> 登录态过期时状态区会提示，点一次重新授权即可；中途关掉浏览器 = 取消，可随时重试。
> 授权信息只存本机 `lib\wb\.browser-profile`，**不会上传**。

> API Key 只用 Windows 自带的 DPAPI 加密后存在本机
> `%APPDATA%\TokenPanel\config.json`，**不会上传到任何服务器**，也只在这台电脑上能解开。

## 四、系统配置里能调什么

右键 → 设置 → 左下角 **`系统配置`**。所有选项**点完立即生效**，不用重启。

| 分组 | 选项 | 说明 |
|---|---|---|
| **界面缩放** | 50% / 75% / 100% / 150% / 自适应 | 调设置面板的大小。小屏笔记本建议 75% |
| **悬浮窗大小** | 小 51 / 默认 68 / 大 85（像素） | 小档会隐藏账户名，只留圆环数字 |
| **外观与显示** | 配色：深色 / 浅色 | 浅色对齐 Windows 11 浅色主题 |
| | **透明度**：100% / 70% / 50% / 30% | 只影响悬浮窗，设置面板始终不透明 |
| | 悬浮窗显示数量（1–5） | 折叠态显示前几个账户，展开态始终全部显示 |
| **启动与查询** | 开机自启 | 登录 Windows 后自动启动，写 `HKCU\...\Run`，不需要管理员权限 |
| | 超时 / 查询间隔 | 网络超时秒数；自动刷新间隔（0 = 不自动刷新） |

**账户显示顺序**：在设置页左边列表用 **`↑ 上移` / `↓ 下移`** 调整，
悬浮窗按这个顺序排，最前面的在最左 / 最上。

## 五、常见问题

**圆圈里显示 `--`**
没数据。三种可能：Key 没填 / Key 错了 / 网络不通。点 `测试脚本` 看具体报错。

**圆圈显示的是哪个额度？**
固定显示 **5 小时**窗口的使用量（`34%` = 5 小时窗口已用 34%）。
展开态能看到 5 小时和 7 天两个窗口，以及各自多久后重置。

**余额显示红色**
余额为负（欠费/透支）或低于 20 元。展开态里会写「已欠费」。

**悬浮窗被别的窗口盖住**
不应该发生——程序会把窗口钉在置顶层。如果确实出现，退出后重新启动；
仍然不行请反馈（附 `app.log`）。

**换了显示器 / 改了缩放比例后显示被裁**
拖动一下悬浮窗就会按新屏幕的缩放重算。程序只在拖动结束时检测，平时不占资源。

**圆角边缘看起来有点毛刺**
这是 Windows 窗口区域裁剪的固有限制（系统不给窗口形状做抗锯齿），
不是显示错误，也不影响使用。想更平滑可以把「透明度」调到 100%，
硬边和桌面的对比降低后观感会好一些。

**想彻底删掉**
退出程序 → 删掉程序文件夹 → 如果想连配置一起删：
`Win+R` 输入 `%APPDATA%\TokenPanel`，把整个文件夹删掉。
开机自启在设置里关掉后会自动从注册表移除。

**多个用户共用一台电脑**
各账户的 Key 是分开加密的，互相看不到。每个人装到自己有权限的目录即可。

## 六、出问题时怎么反馈

用 **`debug-token-pocket.cmd`** 启动（会留一个黑色窗口），复现问题后把窗口里的文字
和 `%APPDATA%\TokenPanel\app.log` 一起发出来。

## 附：文件说明

| 文件 | 作用 |
|---|---|
| `TokenPanel.vbs` | **推荐入口**，双击启动，无黑窗 |
| `创建快捷方式.cmd` | 生成 `TokenPanel.lnk`（一次性操作） |
| `start-token-pocket.cmd` | 兼容入口，内部转调 VBS；cmd 自身窗口会闪一下 |
| `debug-token-pocket.cmd` | 排错用，保留控制台输出 |
| `TokenPanel.ps1` | 主程序 |
| `lib\QuotaCore.ps1` | 数据层：配置、加密、各供应商解析 |
| `lib\ConfigWindow.ps1` | 设置界面 |
| `lib\wb\wb_query.js` | WorkBuddy 积分查询（无头 Chrome，后台运行） |
| `lib\wb\grab_cookie.js` | WorkBuddy 授权登录（点「授权登录」时调用） |
| `make-shortcut.ps1` | 快捷方式生成脚本（由 `.cmd` 调用） |
| `截图\` | 界面截图 |

技术栈：PowerShell 5.1 + WinForms + GDI+ 全自绘，全部代码在你本地运行。
