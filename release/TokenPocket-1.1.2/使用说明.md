# Token Pocket 使用说明

一个小巧的 Windows 桌面悬浮窗，实时显示你各个 AI 套餐的**使用量**和账户**余额**。
不用安装、不用管理员权限、不联网上传任何数据（只向你自己的服务商查额度）。

---

## 一、怎么启动

1. 解压 ZIP 到任意位置（建议放到不常用的盘，比如 `D:\Tools\TokenPocket`，
   放桌面也行，但别放 `C:\Users\你\Desktop` 后被随手删掉）
2. 双击 **`start-token-pocket.cmd`**
3. 屏幕右下角会出现一个小悬浮窗，托盘区（屏幕右下角时间旁边）会多一个图标

第一次启动会自动创建一个示例账户（MiniMax），**API Key 是空的**，所以圆圈里显示 `--`。
填上 Key 之后就有数据了。

> 启动时可能闪一下黑色的命令行窗口，这是正常的，0.1 秒就消失。
> 如果什么都没出现，改用 `debug-token-pocket.cmd` 启动，窗口里会显示错误原因。

## 二、怎么用

| 操作 | 效果 |
|---|---|
| **单击**悬浮窗 | 展开 / 收起（展开能看到每个账户的 5 小时、7 天明细） |
| **双击**悬浮窗 | 刷新：圆环转一圈 + 数字跳动，1 秒后显示最新额度 |
| **拖动**悬浮窗 | 移到任意位置；靠近屏幕**左右边缘**会自动竖排并贴齐，靠近**上下边缘**横排贴齐 |
| **右键**悬浮窗 | 菜单：显示面板 / 立即刷新 / 设置 / 开机自启 / 关于 / 退出 |
| 右键托盘图标 | 同一套菜单 |

## 三、怎么配账户

右键 → **设置**，或点悬浮窗上的「系统配置」再回来。

1. 左边列表选一个账户，或点 **`+ 添加账户`**
2. 选模板（顶部一排）：

| 模板 | 适合谁 | 要填什么 |
|---|---|---|
| **Token Plan** | MiniMax / Kimi / 智谱 GLM 的 Coding Plan | 只填 **API Key**（地址已内置） |
| **官方** | Claude Code / Codex 订阅 | 不用填 Key，自动读本机已登录的凭据 |
| **账户余额** | DeepSeek / 硅基流动 / OpenRouter / 阶跃星辰 的钱包余额 | 选供应商 + 填 **API Key** |
| **通用模板** | 其他 OpenAI 兼容网关 | 填 BaseURL + Key |
| **NewAPI** | 自建或第三方 NewAPI 面板 | BaseURL + Access Token + User ID |
| **自定义** | 任何返回 JSON 的接口 | URL + Key + 提取路径 + 倍数 + 单位 |

3. 填完点 **`测试脚本`**，绿字表示成功、能看到数字
4. 点右下角 **`保存配置`**

> API Key 只用 Windows 自带的 DPAPI 加密后存在本机
> `%APPDATA%\TokenPocket\config.json`，**不会上传到任何服务器**，也只在这台电脑上能解开。

## 四、系统配置里能调什么

右键 → 设置 → 左下角 **`系统配置`**：

| 选项 | 说明 |
|---|---|
| **界面缩放** | 50% / 75% / 100% / 150% / 自适应。点完立刻生效，小屏笔记本建议 75% |
| **悬浮大小** | 小 / 默认 / 大。点完立刻生效，取消会还原 |
| **配色** | 深色 / 浅色（浅色对齐 Windows 11 浅色主题） |
| **显示数量** | 折叠态显示前几个账户（1–5），展开态始终显示全部 |
| **开机自启** | 登录 Windows 后自动启动。写的是 `HKCU\...\Run`，不需要管理员权限 |
| **超时 / 查询间隔** | 网络超时秒数；自动刷新间隔（0 = 不自动刷新） |

账户的**显示顺序**：在设置页左边列表用 **`↑ 上移` / `↓ 下移`** 调整，
悬浮窗按这个顺序显示，最前面的排在圆圈最左/最上。

## 五、常见问题

**圆圈里显示 `--`**
没数据。三种可能：Key 没填 / Key 错了 / 网络不通。点 `测试脚本` 看具体报错。

**圆圈显示的是哪个额度？**
固定显示 **5 小时**窗口的使用量（如 `34%` 表示 5 小时窗口已用 34%）。
展开态能看到 5 小时和 7 天两个窗口，以及各自多久后重置。

**余额显示红色**
余额为负（欠费/透支）或低于 20 元。展开态里会写「已欠费」。

**换了显示器 / 改了缩放比例后显示被裁**
把悬浮窗拖动一下就会自动按新屏幕的缩放重算。程序只在拖动结束时检测，不占资源。

**想彻底删掉**
退出程序 → 删掉程序文件夹 → 如果想连配置一起删：
`Win+R` 输入 `%APPDATA%\TokenPocket`，把整个文件夹删掉。
开机自启在设置里关掉后会自动从注册表移除。

**多个用户共用一台电脑**
各账户的 Key 是分开加密的，互相看不到。每个人装到自己有权限的目录即可。

## 六、出问题时怎么反馈

用 **`debug-token-pocket.cmd`** 启动（会留一个黑色窗口），复现问题后把窗口里的文字
和 `%APPDATA%\TokenPocket\app.log` 一起发出来。
